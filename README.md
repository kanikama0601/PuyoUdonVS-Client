# ぷようどんVS クライアント

香川県の「うどん」をモチーフにした、ネットワーク対戦型の落ち物パズル「ぷようどんVS」のクライアントです。
VB.NET（.NET 10 / WinForms）で作成しています。企画書「6. ネットワークアプリケーション基本計画書」のプロトコル（6.4）に従ってサーバーと通信します。

## 動かし方

```
dotnet run --project PuyoUdonVS-Client
```

Visual Studio では `PuyoUdonVS-Client.slnx` を開いて実行します。

1. タイトル画面で「サーバーのIPアドレス」「ポート番号（既定 8080）」「ニックネーム（10文字まで）」「ルームID」を入力します。ルームIDを空欄にすると自動マッチングです。
2. 「たいせんする！」で `ws://<IP>:<ポート>/udon` に接続し、相手がそろうまで待機画面になります。
3. 2人そろうとカウントダウンのあと対戦開始です。終了後は「再戦する」か「タイトルへ」を選べます。

入力した内容と音量は `%APPDATA%\PuyoUdonVS\client.json` に保存され、次回の起動時に読み込まれます。

## 操作

| キー | 動作 |
| --- | --- |
| ← → （A / D） | 左右移動（押しっぱなしで連続移動） |
| ↓ （S） | 高速落下（押しっぱなしで連続） |
| Space | 一気に落とす |
| X / ↑ （W） | 右回転 |
| Z | 左回転 |
| Esc を2回 | 対戦をやめてタイトルへ |
| M | ミュート |
| PageUp / PageDown | 音量（画面右下のスライダーでも調整可） |
| F3 | FPS 表示 |

左右がふさがった縦向きのうどんは、回転キーを素早く2回押すと上下が入れ替わります。

## ゲームのルール（クライアント側の実装）

- 盤面は 6列×12行。うどんは2つ1組で落ち、4種類（ぶっかけ・鍋焼き・カレー・釜玉）からランダムに選ばれます。
- 同じ種類が縦横に4つ以上つながると消え、上のうどんが落ちて新たに消えれば連鎖です。
- 消えるたびに `CLEAR(消去数, 連鎖数)` を送り、サーバーが計算した数の「おじゃまそば」が相手に届きます。
- 受け取ったおじゃまそばは盤面の上に予告表示され、次にうどんを置いて連鎖が終わったあとに降ってきます（1回に最大30個）。
- 出現位置（左から3列目の一番上、× 印）がふさがると負けです。
- 落下順は `START` の `seed` を .NET の `Random` に渡して作ります。1組ごとに「軸 = Next(1, 5)」「子 = Next(1, 5)」の順に引くので、両プレイヤーに同じ順序で供給されます。
- 相手の落下中のうどんは `OPP_PIECE`（位置のみ）で届くため、種類は「`OPP_STATE` の後に来た最初の `OPP_PIECE` を次の組とみなす」ことで同じ落下順から求めています。

## 通信まわりの動作

- `PING` を5秒ごとに送り、15秒間何も受信しなければ切断とみなしてタイトルへ戻ります。
- `ERROR` を受け取ったらメッセージを表示してタイトルへ戻ります。ただし対戦中・結果画面での 1003/1004 は、決着直後の送信の行き違いでも起こるため、通知だけして対戦を続けます。
- 相手の切断（`OPP_LEFT`）は画面に表示し、`RESULT` の `reason` が `"left"` なら勝ちになります。再戦はできません。

## 構成

| パス | 内容 |
| --- | --- |
| `PuyoUdonVS-Client/Game/` | 盤面・うどんの組・落下順・ゲーム進行（落下、回転、消去、連鎖、おじゃまそば、敗北判定） |
| `PuyoUdonVS-Client/Net/` | WebSocket クライアントとメッセージの組み立て・読み取り |
| `PuyoUdonVS-Client/Audio/` | 効果音とBGM（起動時にプログラムで合成。再生は NAudio） |
| `PuyoUdonVS-Client/UI/` | 画像・フォント、キー入力、設定の保存 |
| `PuyoUdonVS-Client/MainForm*.vb` | 画面遷移・ゲームループ（60fps）・描画 |
| `PuyoUdonVS-Client/Resources/Images/` | うどん・そばのイラスト（exe に埋め込み） |
| `tools/MockServer/` | 動作確認用の簡易サーバー（下記） |

## 動作確認用の簡易サーバー

本番のサーバーができるまでの確認用に、企画書のプロトコルを実装した簡易サーバーを `tools/MockServer` に置いています（C# / ASP.NET Core）。

```
dotnet run --project tools/MockServer -- 8080
```

第2引数で待ち受けるIPを指定できます（既定は `0.0.0.0`）。1台のPCで試すときはクライアントを2つ起動し、IPに `127.0.0.1` を入力します。

テスト用に、クライアントは次のコマンドライン引数も受け付けます。

```
PuyoUdonVS-Client.exe --host 127.0.0.1 --port 8080 --name kai --room udon1 --connect
```

`--autoplay` を付けると自動で操作します（通信の確認用）。`--fps` で FPS 表示が最初から有効になります。

## 素材

うどん・そばのイラストは `PuyoUdonVS-Client/Resources/Images/` の画像を使用しています（配布する場合は素材の出典と利用規約を確認してください）。効果音とBGMはプログラムで合成しています。
